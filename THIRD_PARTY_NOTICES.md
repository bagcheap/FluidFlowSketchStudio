## Cloud provider icons (AWS, Microsoft Azure, Google Cloud)

These icons are **not included** in this repository or in FlowSketch. FlowSketch can import the official icon packages that you download yourself from each provider, after accepting that provider's terms:

- AWS Architecture Icons: https://aws.amazon.com/architecture/icons/
- Azure architecture icons: https://learn.microsoft.com/azure/architecture/icons/
- Google Cloud icons: https://cloud.google.com/icons

Imported icons are converted and stored only in your browser (IndexedDB), and inside the diagrams you use them in. They remain the property of their owners and are subject to the terms you accepted when downloading them. Exporting a library that contains them as a `.flowsketchlib` file copies the icons themselves, so check the provider's terms before sharing one. Don't commit the downloaded packages, or libraries made from them, to this repository.
